# 炸鸡队长 Chickenbro

**聊魔兽、看战斗日志、做云端模拟。**

炸鸡队长是面向魔兽世界玩家的 AI 助手。把职业、装备和打法问题交给鸡哥，结合公开资料、战斗日志与 SimulationCraft 模拟结果，一起找到适合你的选择。

[开始使用](https://www.chickenbro.cloud/) · [使用指南](docs/user-guide.md) · [产品路线图](docs/roadmap.md)

## 和鸡哥聊聊

直接提问，贴上 Warcraft Logs 链接，或者上传一张截图。鸡哥可以查询资料、分析战斗表现，并根据你的追问继续研究。

- **职业与打法讨论**：结合职业、专精和战斗条件，讨论技能机制、天赋及输出思路。
- **战斗日志分析**：围绕具体角色和战斗，查看技能、治疗、增益及关键时间窗口。
- **截图对话**：把装备、属性或游戏画面放进问题中，补充讨论所需的信息。
- **持续追问**：回复流式展示，研究进展与历史会话随时可查；切换会话后可以回来继续。

例如：“帮我看看这场战斗的技能覆盖情况”，或“这两种天赋在单目标下有什么差别？”

## 把选择放进模拟里

在“模拟”页导入 **Raider.IO 角色链接**，检查装备和天赋，设置目标数量、战斗时长等条件，即可提交云端 SimulationCraft 任务，无需在电脑上安装引擎。

- 查看任务进度、输出指标、技能贡献和模拟来源。
- 将完整任务 ID 发给鸡哥，讨论结果或继续实验。
- 对比装备、天赋、施法优先级及食物／属性变化，保留每次任务和原始结果。

当前支持输出与坦克专精。结果用于比较指定条件下的表现；比较时关注战斗条件、模拟误差和引擎版本。

## 三步开始

1. 打开 [chickenbro.cloud](https://www.chickenbro.cloud/)，使用 QQ 登录。
2. 在“队长”中提问、贴日志或上传截图；也可以进入“模拟”导入角色。
3. 查看回答与报告，带着已有会话和任务继续追问。

聊天、图片与模拟历史按账号保存，同一 QQ 账号可在不同浏览器继续使用。网页提供七种插画主题，可以选择喜欢的外观。

## 参与开发

前端使用 Taro H5、React 与 TypeScript，后端使用 Python、FastAPI 和 PostgreSQL；独立 Worker 执行对话与云端模拟任务。
