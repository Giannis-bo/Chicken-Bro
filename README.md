# 炸鸡队长 Chickenbro

你的魔兽世界讨论搭子，也是随手可用的云端模拟助手。

当前产品为 **Web 对话与云端 SimulationCraft，使用 QQ 登录**。打开[炸鸡队长](https://www.chickenbro.cloud/)，点击“QQ登录”并在 QQ 官方页面授权后，即可开始讨论或模拟。

## 对话

输入职业、装备或打法问题，提供 Warcraft Logs 链接，或上传截图让鸡哥结合内容分析。回复流式显示，公开进展、耗时和历史保存在服务端。可以继续旧会话、创建新会话、确认删除历史，以及提交一次不可修改的“是否解决”反馈。

同一账号一次生成一个回复；其他会话或浏览器窗口需要等待。关闭连接不会主动取消已提交的生成；API 重启后可继续读取，Worker 故障则按租约明确失败，不承诺恢复模型会话。

## 云端模拟

在“模拟”中导入 HTTPS Raider.IO 角色链接，核对角色、装备、天赋及战斗参数后提交。任务详情显示进度、失败原因、指标、技能贡献和引擎来源。WCL 可用于战斗讨论与历史资料研究，不是新角色导入入口；暂不支持插件 `/simc` 文本导入或治疗模拟。

复制完整任务 ID 给鸡哥，可以讨论报告，或明确指定装备变化后复用原资料创建新任务。原任务和结果保留，实际比较须核对战斗条件、误差和引擎版本。

## 账号与使用

QQ 身份映射为服务端内部账号，各账号的聊天、图片及模拟记录相互隔离。相同 QQ 账号可在不同浏览器查看自己的服务端历史，退出不删除记录。七种静态插画主题保存在当前浏览器。

小程序产品已废弃；不再提供小程序构建、扫码确认、预览或上传。仓库 `apps/mini-taro` 和 `@wow-mini/*` 是保留的内部路径与包名，实际只交付 Taro H5。
