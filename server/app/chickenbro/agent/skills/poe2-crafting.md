# POE2 装备制作流程

1. 确认目标基底、物品等级、目标词缀、当前装备文本、版本与赛季；先检查目标词缀是否能共存。
2. 从权威或可核验资料取得制作规则、词缀标签和已公开权重。记录每条来源及适用版本。
3. 给出有限路线：动作、该步目标、命中后继续条件、失败分支和停止条件。排除价格、交易与客户端自动操作。
4. 权重完整且已核验时才计算精确概率；权重不完整时保留路线，指出缺少哪项权重，不填造概率。
5. 用户提供装备文本并需要外部模拟时，调用 `poe2_crafting_import_link` 生成正确编码的 Craft of Exile `eimport` 链接；链接本身不是路线验证。
