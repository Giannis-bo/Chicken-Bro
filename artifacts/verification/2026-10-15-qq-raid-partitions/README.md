# 官方 QQBot 团本分区漏查修复

后续用户群截图已展示团本与大秘境正成绩。最新默认上限已改为每类 3 场，并修正分类编号续号，当前状态以[最近三场交付记录](../2026-10-15-qq-recent3/README.md)为准；本文保留分区修复证据。

## 根因与业务证据

用户在 WCL 的 All 页看到 Giannis／白银之手的团本成绩，但机器人默认固定到最新分区 12.1.5，从而漏掉了 12.1 的已有记录。此前「暂无公开记录」只对 12.1.5 成立，不能代表该团本没有成绩。

[真实 API 对照](partition-probe.json)使用同一个角色、Boss 3470、英雄难度、历史 DPS 百分位，仅切换 partition：

| 范围 | 返回 |
| --- | --- |
| 12.1.5（2） | 0 场 |
| 12.1（1） | 4 场 |
| All（-1） | 4 场 |

All 团本汇总最佳平均分 65.22048571428572、中位平均分 57.481314285714284、记录数 24，与用户截图的 65.2、57.5、24 相符。[WCL 官方接口文档](https://tw.warcraftlogs.com/v2-api-docs/warcraft/character.doc.html)明确支持 partition=-1 读取全部分区。

## 修复

- 团本查询默认读取所选团本的全部分区，标题标为「烈毒之渊 · 全部分区」。保持当前团本目录选择、指定 Boss／难度、按战斗时间倒序去重取最近 5 场的规则。
- 大秘境继续限定当前赛季的默认分区。角色身份、私有记录排除和返回分区核对保持有效。
- 保留 Markdown、分数四舍五入取整和按原始分数判色。历史恢复专精记录展示 HPS，输出专精记录展示 DPS。
