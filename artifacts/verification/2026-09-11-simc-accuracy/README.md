## 已定位的代码问题

安装引擎的 `engine/report/json/report_json.cpp:1408` 将诊断输出到 JSON 根 `logs`，级别由 引擎 `error_level_string` 转成 token。羽毛在 `unique_gear_midnight.cpp:2366` 发出 `UNVERIFIED_IMPLEMENTATION`。原 `normalize_simc_report` 只拒绝 error/fatal，之后丢弃其余级别；Worker、get 和 compare 因此无法携带这些机制限制。

修复保留六个有限类别，经独立 `engineDiagnostics` 存入不可变结果，再通过工具读取和双方比较返回。原始 message、路径和角色文本不公开；诊断属于整次模拟，不伪称定位到某件装备。DPS和抽样误差保持原样，限制明确说明不包含机制/实现不确定性。旧结果未采集的诊断不回填；空列表不证明所有机制经过验证。光塔默认值没有对应日志时，也不能由“没有诊断”推断其机制无假设。
