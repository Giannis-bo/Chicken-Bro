# QQ 社交回复按需引用

2026-09-23 用户截图确认：未 @ 的主动文字和群友表情复用已在真实群可见，同时要求不必每条都引用。

## 改动

发送层不再给所有社交回复强制添加引用。普通招呼、接梗、连聊和表情默认直接发送；模型可在多人交错、需要明确指代当前目标时选择 quote=true。模型不能任意指定另一个引用对象，引用 ID 由后端从当前 inbox 取得。长回复只在第一段保留引用，图片失败后的文字降级保持相同选择。

新增 0020_qq_optional_quote.sql，outbox.quote_reply 持久化引用选择，默认 true 保持历史和专业回复兼容；新社交输出默认 false。回退旧代码可继续读取增量库，不删除字段或新写入。
