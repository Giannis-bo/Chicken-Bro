# Web SimC 角色来源与账号绑定

本批由 2026-10-16 用户请求授权：保留 Raider.IO 链接，支持手动名称／服务器／地区（默认国服），账号最多绑定 3 个角色并记住当前选择。

用户在隔离验证后明确授权「发布到线上，验证通过后提交、合入并推送」。已发布正式站并通过下述业务验证。实现基底 `289e0531d8c5916cf8d2b69b98428cfab879079a`；按授权顺序，发布时源码尚未提交，以逐文件哈希固定发布身份。原工作区 QQ 人设等 WIP 单独保留。

## 行为

- 两种输入共用现有快照、预检及云端 SimC 链路。中文服务器名使用 Raider.IO 返回的标准角色 URL 补齐资料；仅接受同地区、同名、HTTPS Raider.IO 标准身份。
- 角色读取成功后可绑定，重复绑定复用已有记录；每个登录 owner 最多 3 个角色。持久化于新增的 `simc.character_preferences`，通过用户行锁串行处理并发绑定、选择和解绑。
- 再次进入或跨浏览器恢复所选角色；支持刷新、切换、解绑和临时角色输入。解绑只移除快捷入口，保留快照及模拟历史。解绑当前角色后选择第一个剩余角色；没有剩余时清空选择。
- 每次新模拟提交前刷新角色资料；同一次不确定提交重试复用刷新后的快照和幂等键，包括切换到任务页再返回的情况。输入变化、切换或解绑使旧快照立即失效，迟到响应不得恢复旧角色。
- 所有读写使用既有 Web 会话、Origin/Host 与 CSRF 保护，客户端不能指定 owner；其他账号无法选择、解绑或绑定他人的快照。WCL 研究快照不能写入 Raider.IO 快捷角色。
