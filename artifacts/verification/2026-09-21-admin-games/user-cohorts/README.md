# 用户按对话游戏独立统计 · 2026-09-21

## 口径

- 魔兽与 POE2 分别按实际提问用户去重，两边都提问过的账号两边各计一次。
- 累计：截至所选结束日，向该游戏发起过至少一次提问的用户。
- 新增：首次向该游戏提问的日期位于所选期间；旧 QQ 账号首次使用另一游戏也算该游戏新增。
- 活跃：所选期间向该游戏提问的用户；失败回复也代表用户发起过提问。
- 仅登录、创建空会话、导入构筑或提交计算均不计入对话用户数。任务、构筑和结果统计保持原范围。
- 日新增、日活跃与卡片采用同一口径；重复提问去重，历史归档会话保留统计，排除测试及合成验收账号。
