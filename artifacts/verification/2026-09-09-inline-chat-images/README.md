# Web 输入框直接输入图片

用户于 2026-09-09 确认：支持 Ctrl/Cmd+V 粘贴和拖入图片，缩略图放在输入框内，保留小图标选择本地文件。基于已发布 QQ/图片整合版本的记录提交 `036aca2b7` 实现，本轮不改后端接口。用户确认预览并授权提交、合入、发布后，已将 `4a519c4c1` 合入 main 并发布 Web，详见 [发布验证](release/README.md)。

三种输入共用文件读取、上传、幂等、数量限制和草稿状态。上传失败留图可重试，读文件或上传期间禁止发送；纯文字粘贴沿用浏览器行为，图文剪贴板保留选区处的文字。格式 PNG/JPEG、单张 5 MiB、总计三张限制保留，超限整批拒绝。图片角标可删除，点击缩略图预览。窄屏文字自动增高至 132px，超过后在文本框内滚动。

先新增失败测试，再实现。24 项针对性测试及全部 278 项前端、62 项控制面通过；类型/lint 通过，H5 构建成功并保留 2 个包体积警告。Chrome 实际 Clipboard API 写图后用 Meta+V 粘贴；DataTransfer 文件拖入、图标选图、三图发送 payload、模拟服务历史刷新及桌面/390px 窄屏检查通过，无浏览器异常。浏览器 API 为隔离的本地模拟，不能据此声称新的公网识图验证。

截图 desktop.png / mobile.png 为编译后 H5，browser-preview.cjs 是可重复验证脚本。源码 SHA 和检查日志摘要见 verification.json。后续隔离候选和公网验证均使用真实 API 与模型，覆盖粘贴、拖入、选图、三图识别、历史和跨账号隔离；使用合成 QQ 测试身份，不代表重新测试 QQ OAuth 登录。
