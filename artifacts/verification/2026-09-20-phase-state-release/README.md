# 通用阶段状态模拟

状态：已发布并完成生产验证。源码 `32add63464e28ea53a9df23690cc1800dbe74953`。

## 功能

结构化 initialState 支持资源值/max、Buff 层数和显式/完整剩余时长、普通单充能冷却。measurement 指定 20–120 秒固定窗口和动作/Buff 携带统计，assertions 指定起手顺序、实际效果及溢出上限。编译器 v7 自动用于阶段任务，既有任务保持原版本。

云端逐次执行并校验 t=0 快照，每次任务共享时间预算、最多128次。max 从真实角色引擎上限发现。任务结果绑定场景、来源、输入、引擎、单次报告哈希。中文报告和 Chat 使用同一聚合结果。
