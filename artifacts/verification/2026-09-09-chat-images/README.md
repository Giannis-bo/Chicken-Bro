## 实现范围

Mini/Web 每条最多 3 张 PNG/JPEG、每张 5 MiB，可纯图或图文提问，预览/移除/上传重试；服务端 started 后清理本次草稿，未变图片请求在不确定失败后复用幂等身份。Mini 以短私有临时路径渲染，避免大 base64 超过渲染桥限制；退出组件清文件，重启清自身前缀残留。历史按用户点击后鉴权读取，不公开图床 URL。

PostgreSQL 私有 bytea 保存规范化图像、owner 与消息关系；绑定/消息/账号并发互斥同事务。旧历史请求不含图片字段，纯图显示 [图片]。按原始内容实际解码、类型与像素校验，清除 EXIF/文本元数据并校正 JPEG 方向。每账号限制 100 MiB/1000 个有效 payload，未发送 24 小时过期，归档立即不可访问、7 天到期；清理命令只清到期字节。生产调度未配置。

Codex 使用真实 image 输入块和历史图片编号映射，最多最近九张；文本不冒充视觉。大图片模型管道写入有 deadline，非读取子进程不会无限阻塞账号。运行面默认关闭新图片入口，能力提示随开关变化。
