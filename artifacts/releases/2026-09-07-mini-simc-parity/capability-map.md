# Mini / Web Simc 能力对照

基准：当前本地 WebSimcView / WebSimcReport，2026-09-07。

| 能力 | 小程序承载 |
| --- | --- |
| 来源、合法链接示例、角色职业专精、就绪状态 | 来源卡、可展开示例、可复制链接、缺项提示 |
| 当前引擎/游戏版本、不可用重试 | 页头版本行与重试；不可用时禁止提交 |
| 四种战斗类型、目标数、战斗时长 | 原生选择器和数字输入 |
| 时长浮动、迭代上限、目标误差 | 精度与增益折叠区，校验与百分比换算 |
| 团队增益、嗜血/英勇 | 原生开关 |
| 配置摘要 | 可展开卡片，底部提交按钮常驻 |
| 跨端同账号任务、状态筛选、分页与刷新 | 独立任务页、状态选择器、纵向任务卡 |
| 角色、场景、结果摘要 | 任务卡展示角色专精、目标、真实指标 |
| 排队/运行/失败/取消、刷新 | 任务详情与有界轮询 |
| 主指标、误差、迭代、平均时长、计算耗时 | 报告摘要 |
| 技能贡献、占比、次数、爆击 | 默认展开纵向技能卡，原索引绑定名称后排序 |
| 增益、资源、属性、装备与天赋 | 按需展开分组，天赋代码可选择复制 |
| 本次配置、历史引擎、来源、名称校验 | 配置分组与运行详情 |
| 历史摘要与缺数据 | 未记录提示，不补造 |

证据：本地 247 前端、62 控制面、类型/lint/WeApp 构建通过；受控报告测试通过。开发者工具当前账号没有模拟记录，本轮没有新建真实模拟，不能将本地参数与报告回归等同云端业务或双端用户验收。
