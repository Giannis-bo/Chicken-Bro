## 功能核对

| 项目 | 本轮结果 |
| --- | --- |
| FAQ | 两端共用同一份内容；认识鸡哥、五历史案例、Simc模拟、账号记录，默认全部折叠；Mini 文字可选 |
| 任务 ID | Mini 列表/详情完整 ID、一键复制、失败可手动复制；实际系统剪贴板一致，复制不打开任务 |
| 会话删除 | Mini 独立删除入口、确认、失败保留；服务端仍拒绝删除正在回复的会话；实际只创建并删除本轮空会话，Web 同步消失 |
| 生成期间历史 | Mini 可切换历史、保留草稿/后台流；两端可新建空会话，其他发送仍由账号级互斥限制 |
| 账号 | Mini 更多菜单显示当前账号与头像，可主动退出、重新微信登录；退出后缓存页面不自动登录，旧退出/迟到登录不会覆盖新状态；Web Cookie 不受影响 |
| 主题 | 同七种主题和色彩目录，Mini 各页及 TabBar 即时生效并保存在当前设备；Web 插画保留，Mini 采用手机布局与颜色，不打包七张大型 Web 插画 |
| Simc 对话换装 | 复用已部署的统一 Chat/Simc 后端，未改编译器/引擎；本轮提供 Mini 获取任务 ID 入口。真实按 ID 换装的后端证据延续 FAQ 发布，未重复冒充新的真机操作 |
