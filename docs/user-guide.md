# 炸鸡队长使用指南

适用范围：1.0 当前已验收功能。客户端最新精简改动的发布状态见 [版本说明](releases/1.0.md)。

## 登录与跨端记录

小程序使用微信登录；Web 在首页展示登录码，用微信扫描并在小程序中明确确认。两端登录同一个账号后，共享对话与模拟历史。Web 头像菜单可以退出登录，退出不会删除记录，也不影响小程序会话。

小程序没有“账号与外观”面板，不提供该面板内的退出、主题选择或头像设置入口。登录确认页仅处理 Web 登录确认；Web 可继续显示已保存头像。

## 对话与历史

在“队长”中直接输入问题，或贴角色与战斗日志链接。回复过程中可以查看历史、切换会话、新建空会话；同一账号当前回复结束前，其他会话和客户端的新发送会提示等待。

小程序“历史对话”打开左侧抽屉，选择会话后收起；Web 使用侧栏。删除按钮需要确认，删除后两端历史都不再显示该会话。正在回复的会话需要等待结束后再删除。删除是历史归档，不承诺立即永久清除服务端数据。

## 提交和查看模拟

在“模拟”中粘贴 HTTPS Raider.IO 角色或 WCL 日志链接，检查导入资料，再设置目标数、时长等参数并提交。国服通过公开来源导入，不提供国服官方英雄榜导入或插件 `/simc` 文本导入。

资料缺失时按提示补充来源，不把不完整快照当成可用模拟。任务详情提供状态、报告、失败原因与引擎信息；提交成功不等于模拟完成。

列表和详情可复制完整任务 ID。把 ID 发给鸡哥并明确替换部位、物品 ID/链接、装等和版本，可以复用原任务资料及条件创建新任务。比较时核对装备差异、战斗条件、误差和引擎版本，原任务不会被覆盖。

## 帮助与外观

小程序“更多”只提供 FAQ 和更新日志。FAQ 四类默认折叠，展开后可查看使用方法与真实案例。Web FAQ 使用独立页面（`/?view=faq`），支持浏览器返回；更新日志使用弹窗。

Web 提供七种静态插画主题。小程序保留适合手机的布局和原有主题渲染兼容，不再提供主题选择功能。两端的记录共享不包含设备本地外观偏好。
