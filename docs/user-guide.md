# 炸鸡队长使用指南

适用范围：Web / QQ 登录版本。

## QQ 登录与账号记录

在网站首页点击“QQ登录”，前往 QQ 官方页面完成授权后返回网站。首次登录会创建 QQ 对应的新账号。取消授权或登录过期时，可返回首页重新点击登录。

每个 QQ 账号分别拥有自己的聊天和模拟历史。Web 账号菜单可以退出登录，退出不会删除记录；再次登录同一个 QQ 账号即可继续查看。

## 对话与历史

可以通过输入框上传截图，图片仅对所属账号可读。回答结束后可以提交一次“是否解决”反馈；确认后不可修改。

在“队长”中直接输入问题，或贴角色与战斗日志链接。回复过程中可以查看历史、切换会话、新建空会话；同一账号当前回复结束前，其他会话和浏览器窗口的新发送会提示等待。

在 Web 侧栏选择历史会话。删除按钮需要确认，删除后历史列表不再显示该会话。正在回复的会话需要等待结束后再删除。删除是历史归档，不承诺立即永久清除服务端数据。

## 提交和查看模拟

在“模拟”中粘贴 HTTPS Raider.IO 角色链接，检查导入资料，再设置目标数、时长等参数并提交。国服通过公开来源导入，不提供国服官方英雄榜导入或插件 `/simc` 文本导入。

资料缺失时按提示补充来源，不把不完整快照当成可用模拟。任务详情提供状态、报告、失败原因与引擎信息；提交成功不等于模拟完成。

列表和详情可复制完整任务 ID。把 ID 发给鸡哥并明确替换部位、物品 ID/链接、装等和版本，可以复用原任务资料及条件创建新任务。比较时核对装备差异、战斗条件、误差和引擎版本，原任务不会被覆盖。

## 帮助与外观

FAQ 四类默认折叠，展开后可查看使用方法与真实案例。Web FAQ 使用独立页面（`/?view=faq`），支持浏览器返回；更新日志使用弹窗。

Web 提供七种静态插画主题，外观偏好保存在当前浏览器。
