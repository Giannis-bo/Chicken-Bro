# 历史 Agent 规格和计划

本目录里的文件是早期实现会话留下的 Agent 执行产物。它们作为历史证据保留，因为 roadmap 条目或日期计划可能会引用它们。

这里不是新工作的活跃规划入口。查看当前项目方向和实现契约时，先看：

- [../README.md](../README.md)
- [../roadmap.md](../roadmap.md)
- [../plans/README.md](../plans/README.md)
- `docs/` 下对应的架构文档或 runbook

如果新任务需要可长期追溯的计划，优先放到 `docs/plans/YYYY-MM-DD-*.md`，并同步登记到 [../plans/README.md](../plans/README.md)。不要再把新的长期项目方向写进 `docs/superpowers/`。
