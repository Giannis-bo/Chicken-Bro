# 元素萨满稳定效果最小验证设计

## 背景

社区装备模板的 v3 导入证据要求来源玩家的稳定效果上下文已验证。当前该上下文只支持奥术和冰霜法师；其他专精即使具备同英雄天赋的真实玩家装备，也会在候选发布前被安全阻断。

本次不将“未知效果”降级为可导入的空效果集。先为元素萨满建立一条可审计的真实效果链路，验证两个英雄天赋模板均能安全导入和正确计算属性面板。

## 范围

- 仅支持 `shaman/elemental`。
- 验证两个英雄天赋：`farseer` 与 `stormbringer`。
- 保留现有来源身份、同职业/专精/英雄天赋匹配、Raider.IO 观测装备和 v3 导入证据的 fail-closed 边界。
- 其余未建模专精仍返回稳定效果不可用，不能因本次改动变为可导入。

## 设计

1. 在服务端稳定效果注册表中增加元素萨满的基础效果和可由已解码来源天赋选择确定的效果；每个效果必须有 SimulationCraft 数据和角色属性样本交叉验证的依据。
2. 为元素萨满增加与该效果集合匹配的已验证属性规则。稳定效果只有在来源天赋导入码成功解码、职业/专精一致且规则可用时才会投影为 `verified` 上下文。
3. 该上下文继续只保存效果 ID 与来源天赋签名，不保存或下发原始导入码。
4. 社区候选仍由原始 Raider.IO 玩家资料选出；在新鲜物化 Gear 快照上构建，并只有当两条元素萨满英雄天赋均通过完整证据、影子校验和导入验证时才允许发布。

## 不做什么

- 不为未知专精声明空效果集。
- 不扩大到其他职业或所有英雄天赋。
- 不引入跨英雄天赋、跨专精或同职业任意装备回退。
- 不把原始抓取暂存快照作为候选 Gear 发布输入。

## 验收

1. 元素萨满两个英雄天赋的有效来源天赋分别投影出与选择相符、可复现签名的稳定效果上下文。
2. 缺少导入码、解码失败、职业/专精不一致或未知专精仍被阻断。
3. 两个社区模板均来自合法 Raider.IO 观测资料，可导入且不泄露原始天赋导入码。
4. 元素萨满属性面板计算结果与用于校验的角色样本一致；无法核实的效果不进入规则。
5. 物化 Gear 候选和 Community 候选的影子校验通过，发布范围外的专精行为不变化。

## 后续扩展

验证通过后，按同一证据标准逐专精扩展；每个专精独立补齐效果映射、属性规则、样本审计和候选验证，不能因已有元素萨满支持而自动放行。
