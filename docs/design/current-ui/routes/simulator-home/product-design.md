# 炸鸡队长主对话目标

来源：用户于 2026-08-01 确认的 Phase 1 体验与 `captain-chat-root-v1.png` target-only 设计稿。

这是一张 853×1844 的队长 Tab 根页。顶部只保留“对话存档 / 炸鸡队长 / + 新话题”；中间是具有充足留白的完整会话；底部只有一行输入和发送。首次进入可显示简短问候，不能显示仪表盘、构筑上下文、推荐问法、上传、粘贴、资料架或固定分析状态。深炭黑、深蓝与低饱和古金维持产品识别，但装饰不得压过文本与对话。

新话题在客户端清空，不立即创建服务端记录；第一条消息才创建会话。底部产品 TabBar 属于全局 shell，不属于队长内容。
