# WoW 小程序 UI v2.2 装饰密度版设计规格

> v2.2 是在 v2.1 密度版基础上的设计感增强稿。目标不是回到概念海报，而是在真实小程序页面内部保留可落地的“效果家具”，让页面更有 WoW 控制台记忆点。

## 核心判断

v2.1 把证据密度收回来了，但视觉被压得偏素。v2.2 保留 v2.1 的高密度结构，同时加入受控装饰组件：战术牌匾、暗铁角标、状态轨、模块 dock、金属分割、细纹材质。

## 可保留的效果家具

- `ornament header`：页面头可以是暗铁牌匾，有金色左上角和蓝色右下角结构线。
- `status spine`：页面左侧允许一条很细的金色状态轨，用于形成控制台纵向骨架。
- `corner brackets`：重要 header 和主结论 slab 可以有角标，但角标不承载假信息。
- `module dock`：四模块状态带可以放入轻量容器，像控制台模块槽。
- `gold rail title`：section 标题左侧可用短金色竖轨增强层级。
- `material surface`：暗铁/奥术材质可作为低透明背景，不覆盖文字可读性。

## 仍然禁止的效果家具

- 伪手机外框、伪时间、伪胶囊、伪系统状态。
- `效果图 01`、演示标签、设计稿说明文字。
- AI 生成的假职业、假专精、假天赋、假装备图标。
- 无来源的数字、官方状态、评分、S/A 级、提升优先级。
- 用绿色表达普通可点状态。

## 页面修正

### 工作台

保留 v2.1 的信息密度：当前专精、主结论、主 action、两个 blocker、四模块状态、证据摘要和阻断详情同屏。增强点是顶部牌匾、主结论材质、模块 dock 和 section 金色轨。

### 资讯

保留首屏 5 条列表。增强点是版本情报牌匾、来源摘要卡的暗铁面、列表行的状态轨和右侧频道 pill。

### 职业 tab

保留账号状态和构筑工作流。增强点是职业控制台牌匾、当前工作台入口的金边、工作流标题轨和入口行的暗铁质感。

## 实施提醒

这些家具都应落为 WXSS 可维护样式，不要依赖整张截图或大背景图。imagegen 资产只可作为低透明材质底，真实对象仍来自接口 icon 和 read model。
