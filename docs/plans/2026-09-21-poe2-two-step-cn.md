## 实现与验收

- 导入时已经执行一次 PoB 计算，将该结果与构筑在同一数据库事务保存为成功的原始任务。无需再次点击计算基线；字段保留引擎版本、输入摘要和原始导出。
- 导入页直接显示角色等级/职业/升华、主要属性（补充力量、敏捷、智慧和精魂）、技能组、计算条件及天赋。历史构筑无基线时按稳定幂等键自动生成；失败提供重试。
- 对比页包含调整表单、自动对比、任务记录和可选择的方案详情。原始树与方案树继续绑定准确输入。保留登录切换、迟到请求隔离。
- 中文作用于展示，不修改 PoB 输入或点数。来源为 PoE2DB `4.5/data_us.json` 与 `4.5/data_cn.json`，下载于 2026-09-21。固定 PoB 仍为 `v0.23.1@7d6f530c`、树 `0_5`。
- 根据完整英文效果（含数值）匹配中文，跨行效果整体匹配。按关键词 ID 与数值校正源数据的 5 对顺序差异；不按节点 ID 直接替换属性，避免动态属性/版本差异。PoB 特定措辞由显式映射翻译，未知未来效果保留原文。原始名称、原始效果保留在 API 中。
- 中文数据生成脚本 `scripts/prepare-poe2-tree-translations.py`，源文件 SHA256 记录于 `tree-zh-CN.json`。修正源站对“战吼使敌人疲惫”额外插入的 1 秒，保持 PoB 实际文本。
