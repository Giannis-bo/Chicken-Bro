# POE2 基线复用与研究预算

> 当前状态（2026-09-21）：已完成。用户已验收并授权发布，运行源码 `77cee1603` 已上线，提交与合入已完成；见[正式发布记录](../../artifacts/releases/2026-09-21-poe2/README.md)。下文 Candidate、禁止提交与待验收等表述记录此前阶段，不代表当前状态。

用户授权：统一基线复用，并增加宽松的研究额度；不增加 Agent 删除或重命名工具。范围为独立 Candidate。

- `poe2_get` 返回当前引擎已有成功 baselineJobId。
- Chat `poe2_calculate` 在持有构筑行锁时检查同构筑、修改、引擎的成功/在途任务，复用不入队、不扣预算。幂等键回放保留原任务；失败后新键才是新尝试。
- 预算复用 chat.research_sessions / research_runs 的持久化 JSON；服务端 owner/run 绑定、行锁串行扣减，不接受模型指定研究身份。
- 每轮 12 次新增方案计算，同研究 60 个不同方案、120 次执行尝试。30 个方案提示收敛，允许继续。读取/轮询/对比/复用免费；失败或入队后中断保留消耗。
- 方案身份由源构筑 hash、当前引擎版本与修改定义；同源重复导入不增加不同方案身份，但再次实际执行仍计尝试。
- 该预算限定 Chat 的 poe2_calculate；导入流程、Web 手动计算保留现有输入/引擎保护，不计入此方案预算。
- 研究结束后可复用/读取已有结果，禁止新增方案计算。正常追问共享累计额度，每轮执行保护重置；不引导拆研究绕过。
- 主规则、分析流程和工具说明统一，保留魔兽来源预算字段。

验证：云端单元测试、PostgreSQL 持久化/并发/账号隔离、真实 Candidate Chat 基线复用及对比。具体结果见 artifacts/verification/2026-09-21-poe2-research-budget。
