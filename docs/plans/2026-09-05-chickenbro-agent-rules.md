## 方案与边界

- 将业务规则集中到 `server/app/chickenbro/agent/AGENTS.md`，不修改仓库根工程指南或云端全局规则。
- Chat adapter 每次调用读取服务端固定文件，通过 Codex `developer_instructions` 注入；读取失败、空文件或超限时拒绝启动。
- 用户历史单独编码为 JSON；保留最近 20 条、每条 4000 字符边界。公开检索、WCL/Raider.IO 路由规则迁入同一文件。
- 保留认证、owner 隔离、工具网关和 read-only sandbox。规则不代替服务端权限控制。
