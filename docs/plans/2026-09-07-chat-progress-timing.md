# 双端聊天过程与时间

状态：`正在推进`；用户于 2026-09-07 确认实施。

## 用户体验与范围

- Mini/Web 在回答上方流式展示上游公开摘要，正文开始或终态时自动折叠，可手动展开；无摘要时沿用真实等待状态。
- 每条回复展示服务端完成时间及开始至结束的总耗时。历史回复无耗时来源时不编造耗时。
- 服务端保留公开摘要，成功与失败均可从任一端读取；失败标记“未完成”。不暴露原始模型思维链、commentary、工具参数/输出、凭据和内部日志。

## 实现与验证

沿用 Chat application/repository 与 Mini/Web 共用 ChatModel。新增 additive migration `0004_chat_public_progress`、受限 `progress` SSE 事件和可选终态时间字段，消息历史增加可选 `progress` 对象。保存后发送、owner 校验、幂等回放与旧消息兼容保持现有边界。

验证：原生 stdio 摘要/私密字段隔离、流状态与折叠交互、双端历史与失败恢复、真实隔离 PostgreSQL 迁移及 owner 校验、前后端回归、控制面、类型/lint 与双端构建。

## 发布边界
