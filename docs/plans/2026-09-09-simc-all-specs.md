# SimC 全职业专精支持

2026-09-09 用户要求全职业专精开放，并明确治疗专精直接提示“SimC 不支持治疗专精进行模拟”。本轮不改引擎、不新增来源供应商、不开放治疗模拟。

## 行为与验收

- 统一 40 专精目录，`WOW_SIMC_SUPPORTED_SPECS=all` 开放 33 个输出/坦克专精；7 个治疗专精在 readiness 和 compiler 均明确拒绝。保留显式关闭配置与未知职业/专精拒绝。
- API/Worker、正式/候选 unit 使用同一配置语义；发布时须覆盖实际运行进程中的旧环境文件名单，不能仅更新仓库 unit。
- Raider.IO 的 `death_knight` / `demon_hunter` 在编译边界转换成 SimC 的 `deathknight` / `demonhunter`，原始角色来源保持不变。
- 引擎不可用、未知专精、专精未开放、治疗限制分别提示。服务端限制不要求用户补资料。
- 增辉保留引擎自带简化队友模型，只允许当前引擎已核验的默认队友集合，选择唯一目标角色及对应技能身份；不累计队友 DPS。提交页和报告明确模型局限。其他多角色报告继续拒绝。
- 坦克报告评估 DPS，不宣称生存能力。真实数据完整性与天赋/装备版本兼容仍由既有链路检查。
