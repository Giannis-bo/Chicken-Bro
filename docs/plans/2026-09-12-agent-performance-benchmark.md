# 复杂研究效率配对基准

2026-09-12 用户批准：四类各两题、含跨轮追问；固定资料回放后验证真实链路；同模型配对、保留缓存/失败、质量优先。仅评测，不修改或发布产品行为。

目标：检验已上线按需流程相对旧版是否在同等质量下加速。预设参考门槛为复杂题整体中位完整耗时下降15%，各类不明显退步，质量通过率不降低；小样本不声称P90改善。

基线：旧版b406fc915与现版2294cb95，同gpt-6-astra/low及现有云端依赖。固定回放使用同一工具响应集合与工具schema，保留现版新增流程读取；禁用双方原生联网，公开研究经同一个fixture网页工具，以隔离模型/编排差异。它不是原生搜索或真实引擎测速。

架构：评测专用MCP回放器、固定8题及rubric、真实Codex适配器计时包装、配对汇总。每题3次A/B、交替顺序；少量多轮题按完整会话顺序执行。每次输出持久化、明确工具响应范围、无真实业务副作用。按run绑定观察；tool interval取并集，余时称“非工具耗时”，不能冒充纯模型推理耗时。
