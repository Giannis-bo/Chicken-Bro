# SimC 场景实验实施计划

**授权**：用户于 2026-09-09 确认两个案例的通用方案并要求开始落地。用户随后明确“OK，提交，合入，发布”，授权本次提交、合入与生产发布。已存在资料可读，不安装依赖、不在本地运行 SimC、不改其他任务证据。

**目标**：装备指定替换与无候选天赋优化，共享完整任务上下文、版本资料查询、场景预检、云端执行及可核对的比较结果。

**架构**：保留不可变来源快照；scenario 保存覆盖配置，baseJobId 继承上次有效配置。Simulation application/compiler 拥有合法性、哈希和所有权，Chat MCP 提供查询、预检、提交、比较。引擎和资料版本不一致时拒绝编辑；缺少前置规则不伪称完整合法性。

**技术**：现有 Python/FastAPI、PostgreSQL 队列、Taro/TypeScript、原生 MCP；复用版本化资料与现有测试环境。
