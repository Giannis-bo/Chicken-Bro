# 同账号单个活动回复

状态：`正在推进`（本地实现，待用户体验）

## 已确认范围

2026-09-07 用户确认：同一内部 `user_id` 在 Mini/Web、多个窗口和多个会话之间，同时只允许一个正在生成的回复。允许新建空会话、查看历史；已有回复结束前发送新消息应提示“鸡哥正在回复你的另一条消息，请等待回复结束后再发送。”同一会话的新消息也受限；不同账号独立。正常完成、失败和超时后恢复，重复请求保持幂等。

## 实现与边界

- `0005_chat_account_concurrency.sql` 对 `chat.agent_runs(user_id)` 的 streaming 状态建立唯一索引，跨 API 进程原子互斥。拒绝时整个消息/run 事务回滚，不留下未受理消息。
- Repository 将该约束冲突转为领域错误，Application 先做幂等冲突核对/重放，再返回 `CHAT_ACCOUNT_BUSY`；HTTP 为 409。
- 复用原有执行超时加宽限期回收，范围扩大为当前账号全部会话，处理重启遗留的活动记录；其他账号不受影响。
- 双端 SSE transport 解析结构化错误码，ChatModel 显示等待说明；切换/新建会话保留旧回复连接，旧事件不能覆盖新会话。退出销毁模型时释放连接。
- 沿用已安装依赖。工作树 `/Users/boyuan/Documents/wow-chat-account-limit`，分支 `codex/chat-account-limit`，基线 `29effdfbc5aef0adff4b3e3ff61aa2fa278ea45f`；原目录的界面 WIP 保留。
