## 实现

- Web 使用独立垃圾桶按钮，避免嵌套按钮或误触打开会话。原生 dialog 提供取消、删除、进行中状态与错误说明，默认焦点为取消，取消后恢复焦点。
- DELETE `/api/v2/chat/conversations/{id}` 通过既有 Principal 与 CSRF 校验。服务端将当前账号的会话标记 archived，列表和详情不可再读，幂等重建不恢复会话；重复删除成功，不物理清除消息。
- 删除与发送都锁定会话行，避免同时删除和发起回复；streaming 时拒绝删除，沿用既有超时回收。无需新数据库 migration 或额外运行权限。
- ChatModel 仅在服务端确认成功后移除列表/当前内容，失败保留会话；防止延迟分页、历史恢复及导航失败带回已删除会话。
- 原目录的主题设计 WIP 未修改。当前隔离工作树 `/Users/boyuan/Documents/wow-chat-account-limit`，分支 `codex/chat-delete`，基线 c1acfca5e。
