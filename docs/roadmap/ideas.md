# Roadmap Ideas

这里只保留尚未进入正式里程碑且仍有决策价值的想法。已完成事项和执行流水不在这里归档。

## 维护规则

- 用户认可且可执行的方向进入 `docs/roadmap.md`。
- 已废止、已完成或被当前计划替代的条目直接删除。
- 每条候选只记录问题、价值、边界、建议里程碑和状态。
- 状态使用：`待补录`、`待确认`、`候选`、`待规划`、`后续`、`暂缓`。
