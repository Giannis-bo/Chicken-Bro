## 唯一产品方向

项目只保留炸鸡队长会话与 SimC 模拟任务。微信小程序与 Web 使用独立认证会话，但映射到同一个内部用户并共享服务端 Chat/SimC 数据。正式体验不依赖网站 OAuth、UnionID、prototype bypass 或客户端数据拼接。

## 用户可见完成标准

- 小程序与 Web 登录同一微信用户后，看到相同会话、完整消息和 SimC 历史。
- 任一端创建或续聊会话，另一端可继续；任一端提交 SimC，另一端可查看同一任务与语义结果。
- 两种 Session 可独立退出和过期，不改变数据 owner；不同用户严格隔离。
- 正式客户端只呈现“队长”和“SimC”两个 Tab，不再出现已移除产品入口。
- 失败显示真实、可恢复状态，不用模板、旧缓存或 return code 冒充成功。
- 旧文档、代码、服务、数据库和数据只在新系统稳定且恢复验证通过后按精确清单退役。

## 整体完成门槛

只有在真实 Mini/Web 验收、生产切流、首条新写入、稳定健康、已接受生产数据的恢复演练、精确本地/云端清理、清理后再次验收、回滚窗口到期，以及本地/origin/生产身份一致全部成立后，项目才可标记 `已完成`。被明确拒绝的四个 evidence/test 库不建立恢复副本，也不构成业务恢复权威。
