## 1.0 已完成

| 能力 | 当前产品范围 |
| --- | --- |
| 炸鸡队长对话 | 公开资料研究、WCL 讨论、流式回复、公开进展与耗时、服务端历史 |
| 对话管理 | 双端继续、Mini 历史抽屉、确认删除、生成中查看历史、账号级单回复互斥 |
| 云端 SimC | Raider.IO 导入、资料校验、模拟参数、任务进度与报告、完整任务 ID 复制 |
| 对话操作模拟 | 读取本账号任务、复用参数和快照、明确换装后创建新任务并比较 |
| 登录与共享 | Mini Bearer / Web Cookie 独立，服务端映射同一账号；扫码确认登录 Web |
| 帮助与外观 | 双端 FAQ/更新日志、Web 七张静态主题；Mini“更多”仅 FAQ/更新日志 |
| 数据与运行 | Identity/Chat/SimC/Worker 所有权边界、白名单迁移与旧系统退役历史已完成 |

小程序“账号与外观”面板已按最新决定取消，先前“全功能对齐”不再要求小程序提供账号面板、主动退出与主题选择。Web 账号菜单和已保存头像显示继续保留。
