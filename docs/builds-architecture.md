# 职业专精 Tab 前后端方案

## 产品目标

职业专精 tab 从原来的“BD”入口升级为可学习、可抄作业的构筑中心。玩家进入该 tab 后，先通过顶部 banner 理解能力范围，再从四个查询入口中选择要学习的模块：

- 天赋构筑
- 装备获取
- 属性权重
- 输出循环

每个查询入口都会进入独立详情页。详情页中再用下拉框选择职业和专精，并展示该模块的详情。热门专精模块保留为资讯类信息展示，用于推送近期高端玩法趋势，而不是替代完整查询。

## 前端结构

当前页面仍由 `pages/builds/builds` 承载：

- `app.json` 将底部 tab 文案改为“职业专精”。
- `pages/builds/builds.wxml` 删除原来的 13 个职业、39 个职业专精统计栏。
- 顶部 banner 保留，用于说明该 tab 的整体能力。
- 查询入口固定为四个：天赋构筑、装备获取、属性权重、输出循环。
- 主页面不铺开职业和专精列表，避免把 tab 做成信息墙。
- 点击任一查询入口后通过 `wx.navigateTo` 进入 `pages/builds/detail`。
- 详情页中用两个 `picker` 下拉框选择职业和专精，再展示当前模块详情。
- 热门专精只作为资讯卡片展示来源、发布时间和分析窗口。

## 子模块 UI 设计

四个子模块的信息密度和阅读目标不同，不能复用同一种“文本列表”：

- 天赋构筑：优先展示可复制的天赋导入代码，然后展示适用场景、核心节点和可替换点。UI 使用 `talent-code-card` 承载导入代码，下面用要点列表解释为什么这么点。
- 装备获取：玩家关心“穿什么”和“去哪拿”。UI 使用 `gear-list`，按部位展示装备名、来源副本/首领/制造/兑换，并补充替代选择。
- 属性权重：玩家需要快速判断副属性方向。UI 使用 `stat-bars`，把暴击、急速、精通、全能等属性做成权重条，同时保留样本窗口和适用边界，避免把趋势当作个人 Sim 结论。
- 输出循环：玩家需要照着练。UI 使用 `rotation-timeline`，按起手、爆发、平稳期、AOE/单体切换、资源溢出处理分阶段展示。

## 数据契约

`server/builds/home-payload.js` 先沉淀后端 payload 契约：

- `buildSpecializationHomePayload()`：返回职业专精 tab 首页所需数据。
- `getSpecializationDetail(id)`：返回某一专精的四类详情。
- `queryTypes`：固定定义四个查询入口。
- `classOptions`：按职业分组的 39 个职业专精，用于子窗口下拉选择。
- `trustedBuildSources`：可信来源白名单。

当前数据层重点解决两件事：

1. 主 tab 聚焦四个查询入口，不把全部职业专精直接铺在首页。
2. 子窗口可以通过职业和专精下拉框覆盖全部 39 个职业专精。
3. 页面不会再依赖无结构的写死文案。
4. 所有可见专精、详情和热门卡片都必须带来源字段，避免无来源结论进入前端。

## 可信来源

职业专精构筑必须来自可追溯来源，至少包含：

- Raider.IO：高层大秘境排名、队伍、角色和专精样本。
- Warcraft Logs：团本和大秘境战斗日志、技能覆盖、伤害构成和排名样本。
- Archon：基于 Warcraft Logs 的职业、天赋、装备和统计聚合。
- Subcreation：大秘境和团本构筑趋势聚合。

后续如果接入 Wowhead、Icy Veins、官方热修或职业改动说明，也必须进入可信来源白名单，并保留 source URL、发布时间、分析窗口和来源说明。

## 定时分析方案

后端定时任务建议按以下节奏刷新：

- 每日刷新：拉取 Raider.IO 高层大秘境样本、Archon/Subcreation 构筑聚合和 Warcraft Logs 排名样本。
- 大版本或热修后强制刷新：职业改动、套装调整、饰品修正后立即重算受影响专精。
- 每条结论保留 `publishedAt` 和 `analysisWindow`，让玩家知道结论来自哪个时间窗口。
- 低样本专精不输出强结论，只展示“样本不足”状态。

## API 建议

生产环境可在现有轻量后端旁新增：

- `GET /api/builds/home`
- `GET /api/builds/detail?id=<specializationId>`
- `POST /api/builds/refresh?mode=manual|scheduled`

响应必须包含：

- `sourceName`
- `sourceUrl`
- `publishedAt`
- `analysisWindow`
- `sourceNote`

缺少任意来源字段的数据不得进入首页或详情页。

## 准确性边界

职业专精数据会随版本、热修、团本开放进度和大秘境词缀变化而快速漂移。因此页面只展示带来源、带时间窗口、带样本说明的数据。没有完成定时采集和校验前，不应该把人工编写的“最优天赋”“毕业装备”作为真实结论发布。
